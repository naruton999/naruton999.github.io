遊び方
  • パドル: マウス / 画面ドラッグ / ← → A D
  • 発射: 画面タップ / Space（開始後はクリック / Space で発射）
  • ポーズ: P / Esc / 一時停止ボタン
  • PCでは開始時にマウスを固定します（Escで解除）。固定できない場合は画面外のマウスにも追従します。
  • 画面からボールがすべて無くなったらミスです。マルチボール中は1球落ちても、ほかの球が残っていれば続行します。

※ BGM はブラウザの自動再生制限により、最初のタップ・キー操作から再生されます。
