Demo RPG操作デモ「光の勇者」

スマホ向けRPGの画面・タッチ操作を確認するためのデモです。試作版「光の勇者」で、縦長画面と十字キー・A / B の操作性を確かめられます。

スマホは縦向き推奨。音は最初 OFF です。

Lv.1 HP 34/34 MP 14/14 30G

タイトル画面です。Aボタンで開始します。

BGM / SOUND

BGMと効果音をまとめて切り替えます。

遊び方

「光の勇者 〜伝説の剣と魔王〜」は、魔王ダルゴスを倒すため、光の剣を求めて4つのエリアを巡る王道ファンタジーRPGの操作デモです。 ゲーム内容はローカル試作のままで、縦長画面とタッチ操作の検証を目的としています。

操作

  • 移動: 十字キー / ←↑↓→ / WASD
  • 決定・話す・調べる: A / Z / Enter / Space
  • 戻る: B / X / Escape
  • 音: 画面上の「音 ON/OFF」/ M
  • タイトル・会話・ゲームオーバー・エンディングは、画面タップでも進めます。
  • バトルのコマンド・呪文・道具は、項目を直接タップしても選べます。

はじまりの村

長老に話しかけると、旅立ちの準備が整います。全滅すると村で復活します（所持金は半分になります）。

音はブラウザの自動再生制限のため、最初のタップ・キー操作から有効になります。
