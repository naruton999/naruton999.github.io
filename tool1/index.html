Tool 8bit チップチューン プレイヤー

ファミコン風4和音（Pulse×2 + Triangle + Noise）を Web Audio API で鳴らすサンプルです。

Pulse 1 LEAD
Pulse 2 HARMONY
Triangle BASS
Noise DRUMS
▶ 再生 を押すと演奏が始まります

▶ 再生 を押すと選択中の楽曲が流れます

🎵 スコアエディタ

初期値は選択中の楽曲の先頭64ステップ（4小節）です。書き換えて「適用して再生」を押すと、その内容で演奏します。

🎹 使い方

  • 楽曲選択: セレクトボックスでサンプル楽譜4曲（タイトル / フィールド / バトル / 喜びの歌）から選べます
  • 再生: ▶ 再生 ボタンで選択中の楽曲を演奏します
  • 停止: ■ 停止 ボタンで演奏を中断します
  • ミュート: ミュート ボタンで音だけを消せます（演奏は継続）
  • 楽譜編集: 楽譜エディタ ボタンで開閉し、適用して再生 で入力内容を演奏します

🔊 4チャンネル構成 (NES pAPU準拠)

Pulse 1 (矩形波 25%): 主旋律・リードメロディ
Pulse 2 (矩形波 12.5%): 対旋律・ハーモニー
Triangle (三角波): ベースライン・低音パート
Noise (ノイズ): スネア・キックなどのドラム

📝 楽譜データの書き方

音符: ['C4',4] = C4 を4ステップ分
休符: ['OFF',2] = 2ステップ分の休み
音名: C4 / F#3 / Bb2 (フラット表記も可)
ドラム: 0=休 1=スネア 2=キック 3=両方（1マス = 8分音符）
